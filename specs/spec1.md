# 現在時間（數位時鐘）功能開發規格書

## 1. 功能目的

提供簡潔、清楚且持續更新的當地日期與時間，讓使用者從首頁進入獨立的數位時鐘頁面，即可查看現在時間，無須手動重新整理。

本文件聚焦使用流程、畫面呈現、商業規則與驗收條件，不包含程式碼、技術架構或實作方式。

## 2. 已確認的需求決策

| 項目 | 確認內容 |
| --- | --- |
| 入口名稱 | 現在時間 |
| 入口位置 | 首頁主要內容上方 |
| 開啟方式 | 在同一瀏覽器分頁進入獨立時鐘頁面 |
| 時間依據 | 使用者裝置設定的目前時間及時區 |
| 日期格式 | 西元年 `yyyy/MM/dd` |
| 時間格式 | 24 小時制 `HH:mm:ss` |
| 主要目的 | 持續顯示當地日期及時間，畫面保持簡潔 |

原始大綱中的 `hh:mm:ss`，依已確認的 24 小時制需求統一記為 `HH:mm:ss`。

## 3. 使用流程

1. 使用者開啟首頁，在主要內容上方看到「現在時間」按鈕。
2. 使用者點擊按鈕，在同一瀏覽器分頁進入時鐘頁面。
3. 頁面即顯示裝置當地日期及時間，不需要再次點擊或輸入資料。
4. 使用者停留於頁面時，時間持續更新，日期隨跨日同步變更。
5. 使用者可透過既有首頁導覽或瀏覽器返回功能回到首頁。

## 4. 畫面與操作需求

### 4.1 首頁入口

- 按鈕文字固定為「現在時間」。
- 入口位於首頁主要內容頂端，應容易辨識及操作。
- 不因本功能在全站導覽列新增另一個時鐘入口。

### 4.2 時鐘頁面

| 顯示項目 | 位置及規則 | 範例 |
| --- | --- | --- |
| 現在日期 | 時鐘頁主要內容區左上方，依固定日期格式顯示 | `2026/11/20` |
| 現在時間 | 主要內容區正中央，以清楚易讀的數位電子鐘形式呈現 | `21:05:03` |

- 時間是主要視覺焦點，應比日期醒目，數字及分隔符號須容易辨讀。
- 本文件所稱「左上方」及「正中央」均以時鐘頁主要內容區為準。
- 不需操作即可查看日期與時間，不設開始、暫停或手動更新按鈕。
- 畫面保持簡潔，不加入與查看時間無關的資訊或裝飾性動畫。
- 桌面與手機畫面均須完整顯示日期及時間，不得重疊、截斷，或必須水平捲動才能閱讀。
- 時間數字變動時，應維持穩定位置，避免影響閱讀。

## 5. 商業規則

### 5.1 時間來源與當地時區

- 顯示值以使用者裝置設定的目前日期、時間及時區為準，不以網站伺服器所在地作為顯示依據。
- 不同時區的使用者可看到不同的日期及時間；這是正常且預期的結果。
- 即使裝置設定的時區與使用者實際所在地不同，仍依裝置設定顯示，不另行判定地理位置。
- 若裝置時間不準確，顯示結果也可能不準確；本功能不校正裝置時間，也不保證與標準授時一致。
- 本功能不要求使用者提供定位權限。

### 5.2 日期顯示

- 使用西元日期，格式固定為 `yyyy/MM/dd`。
- 年份顯示四位數，月份及日期不足兩位數時補零，例如 `2026/01/05`。
- 日期須與同一時區下的時間一致，不得出現日期已跨日但時間仍屬前一日的矛盾狀態。
- 月底、年底及閏年日期均依裝置當地日期正確轉換。

### 5.3 時間顯示

- 使用 24 小時制，格式固定為 `HH:mm:ss`，不顯示上午／下午。
- 小時範圍為 `00` 至 `23`，分鐘及秒數範圍為 `00` 至 `59`。
- 小時、分鐘及秒數均補足兩位數，以半形冒號分隔，例如 `09:05:03`。
- 午夜顯示為 `00:00:00`，不得顯示為 `24:00:00`。

### 5.4 首次顯示與持續更新

- 進入頁面後即顯示當下日期與時間，不需使用者啟動時鐘。
- 頁面正常顯示期間，每秒更新時間，無須手動重新整理頁面。
- 每次更新的顯示結果應反映裝置當下時間，不得只依進入頁面時的初始值持續累加，以免中斷後產生落差。
- 秒、分、小時進位，以及日期切換均須正確；跨午夜時，日期與時間須一併更新。

### 5.5 背景、休眠及設定變更

- 頁面位於背景、裝置鎖定或休眠期間，不要求維持畫面每秒更新。
- 使用者返回時鐘頁且裝置恢復正常運作後，應於一秒內顯示當下日期及時間，不停留在離開前的數值，也不逐秒補播經過的時間。
- 頁面正常顯示期間，若裝置時間或時區改變，應於一秒內反映新的設定，無須重新整理。
- 若設定變更造成時間向前或向後跳動，依變更後的裝置時間顯示，不強制維持連續遞增。

## 6. 功能邊界

- 本功能僅提供目前日期與時間的查看，不涉及使用者輸入、資料新增、修改或刪除。
- 不包含鬧鐘、倒數計時、碼表、世界時鐘、手動選擇時區及個人化設定。
- 不包含網路校時、伺服器時間查詢或裝置時間校正。
- 不因本功能新增登入要求或權限管理流程。
- 本次工作僅完善此規格文件，不實作首頁入口或時鐘頁面，不變更程式碼及設定。

## 7. 驗收條件

驗收時，以受測裝置當時的時間與時區設定作為比對依據。除另有說明外，測試應在裝置正常運作、時鐘頁顯示於前景的情況下進行。

| 編號 | 情境／操作 | 預期結果 |
| --- | --- | --- |
| AC-01 | 開啟首頁 | 主要內容上方可見「現在時間」按鈕。 |
| AC-02 | 點擊「現在時間」 | 在同一瀏覽器分頁進入獨立時鐘頁面。 |
| AC-03 | 首次進入時鐘頁 | 不需額外操作，即於左上顯示日期、中央顯示當下時間。 |
| AC-04 | 裝置日期為 2026 年 1 月 5 日 | 日期顯示為 `2026/01/05`。 |
| AC-05 | 裝置時間為上午 9 時 5 分 3 秒 | 時間顯示為 `09:05:03`。 |
| AC-06 | 裝置時間為下午 9 時 5 分 3 秒 | 時間顯示為 `21:05:03`，無上午／下午標示。 |
| AC-07 | 持續停留至少 10 秒 | 秒數持續更新，顯示時間與裝置當下時間一致，無須重新整理。 |

| AC-09 | 時間由 2026/11/20 的 23:59:59 跨日 | 日期轉為 `2026/11/21`，時間轉為 `00:00:00`。 |

| AC-11 | 跨閏年二月日期 | `2028/02/28` 跨日為 `2028/02/29`，再跨日為 `2028/03/01`。 |
| AC-12 | 於同一時刻，分別使用設定為不同時區的裝置查看 | 各裝置依自身時區顯示當地日期及時間，不固定為台灣時間。 |

| AC-14 | 裝置鎖定或休眠後，恢復運作並返回時鐘頁 | 一秒內恢復顯示當下日期及時間。 |
| AC-15 | 顯示期間修改裝置時間，包含向前及向後調整 | 一秒內依新時間顯示，無須重新整理。 |
| AC-16 | 顯示期間修改裝置時區，包含造成跨日的變更 | 一秒內同步反映新時區對應的日期及時間。 |
| AC-17 | 使用桌面及手機瀏覽 | 日期、時間完整且易讀，無重疊、截斷或水平捲動問題。 |
| AC-18 | 透過既有首頁導覽或瀏覽器返回功能離開 | 可回到首頁並再次進入時鐘頁。 |
